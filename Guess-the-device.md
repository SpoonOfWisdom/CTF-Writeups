# Case Study: Network device identification
**Network Devices**

## Briefing summary
What device is responsible for directing data packets between different networks and uses IP addresses to make forwarding decisions?

## Overview
There are several network different devices that all function together and each serves it's own role.
Some common devices are:
1. **Modem** Translates digital data to analog signals to connect a local network to an ISP
2. **Router** Connects multiple distinct networks together and directs data packets using IP addresses
3. **Switch** Connects devices within the same LAN and forwards data using MAC addresses.

## Takeaway
**Routers** operate at level 3 on the OSI model, which is where IP addresses are handled.
