# Case Study: Availability

## Briefing Summary
What part of the CIA triad involves making sure that users that are authorized to resources have access to those resources?

## Overview
There are 3 pillars to the CIA triad:
1. **Confidentiality** this refers to the security of the resource it is protecting, it ensure that only authorized users have access to it.
* MFA, Encryption, ETC.
2. **Integrity** this refers to the credibility of the information, it ensures that no unauthorized changes are made to it.
* Digital signatures, Hashing, Version control
3. **Availability** this refers to whether an authorized user is able to access the data and whether it is functional, it ensures that the data is available.
* Backups, Redundancy, Disaster recovery.

## Takeaway
The CIA triad is a foundation for guiding information security, protection of data, and to evaluate system vulnerabilities.
