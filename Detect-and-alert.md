# Case Study: Network security device
**Security Systems**

## Briefing Summary
Identify the name of the system that monitors network traffic for suspicious activity.

## Overview
There are multiple systems that monitor network traffic.
1. **IPS** An intrusion prevention system that actively monitors and blocks suspicious activity, mitigating it.
2. **IDS** A passive security tool that monitors network traffic and logs any suspicious activity it finds.
_there are more systems however these are the most relevant ones to this specific example_
The **IPS** is the system that monitors for suspicious activity.

## Takeaway
IDS only monitors internet traffic while IPS deals with suspicious activity in internet traffic.
